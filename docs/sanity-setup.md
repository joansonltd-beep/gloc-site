# Editing site content in Sanity

Open https://www.joansonbjames.com/studio and sign in to the existing project.

For each document whose copy you want to use on the new website:

1. Open the document in Studio.
2. Review and update all text for the Jamaican audience and the current business details.
3. Select Content edition, then Jamaica.
4. Publish the document.

Do not mark legacy market copy as Jamaica without reviewing it. The website uses bundled Jamaica copy until the document is marked jamaica-v1. Existing WhatsApp and social contact channels and the personal portrait are preserved from Site settings.

The current family cover tool uses the visitor's own figures. The savings illustrations use the visitor's own return and inflation assumptions. Legacy calculator-rate and treatment-cost documents do not control those tools.

Changing production CMS documents is a separate action from deploying code. The seed script only creates missing documents and does not replace existing copy.
